# shadcn/ui playground template

This is a shadcn/ui playground template.

- Router: Next.js
- Linter & Formatter: [@biomejs/biome](https://github.com/biomejs/biome)
- Default shadcn/ui preset: [`b7pVGhj99e`](https://ui.shadcn.com/create?preset=b7pVGhj99e)
- Markdown: [@opticlm/streamup](https://github.com/OpticLM/streamup) with [shadcn/typeset](https://ui.shadcn.com/docs/typeset) (see [globals.css](./app/globals.css)'s `.typeset-docs` section)
